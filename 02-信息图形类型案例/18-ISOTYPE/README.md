# ISOTYPE

本标签的属性为基础设计方式。ISOTYPE 用图形符号及其组织规则传达信息与统计数据，可以应用于多种信息图形类型。仓库通过此标签记录案例使用的方法，并与具体图形类型交叉关联。

[返回标签索引](../README.md)

## 基本方法

ISOTYPE 的全称为 International System of Typographic Picture Education。它通过简化的人物或事物符号，将信息整理为具有一致规则的视觉表达。用于数量比较时，以相同大小的符号重复排列表示数量增加，并以图例说明每个符号代表的数量。方法依据见 [Isotype Revisited 的介绍](https://isotyperevisited.org/2012/08/introduction.php)。

## 本库的案例分析重点

- 符号与含义的对应关系，以及同一符号在整幅图中的一致性。
- 每个符号的计量单位、重复数量和余数处理方式。
- 行列、间距、对齐与分组如何帮助读者计数和比较。
- 颜色与简短文字如何辅助分类、说明口径和引导阅读。
- 该方法如何与案例中的时间轴、地图、比较图或混合型版式结合。
