# 文字型与列表型信息图形

文字型／列表型信息图形（Informational / List Infographics）将条目、定义或说明组织成便于扫读的版式。先确定条目顺序是否表达优先级、步骤、字母索引或仅用于定位。用一致的标题与字段支持比较，按需要加入符号与小型统计图。案例分析应记录分组规则、阅读顺序、条目长度差异和图形是否提供独立信息。
