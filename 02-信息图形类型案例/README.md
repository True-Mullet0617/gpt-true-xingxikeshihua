## 修订方式

每次新增案例，先记录图中可见事实及其出处，再分析数据结构、计算口径、视觉编码、信息架构与阅读顺序。将有证据支撑的原则、方法及适用条件写回对应说明和概念定义，附案例链接与修订日期。遇到相反案例时，补充边界条件或保留待验证问题。
