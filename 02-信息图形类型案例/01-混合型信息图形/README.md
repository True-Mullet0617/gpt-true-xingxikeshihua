# 混合型信息图形

混合型信息图形（Mixed Charts）围绕同一叙事任务，将统计图形与文字、符号、ISO 图形或示意图组合。先确定各组成部分回答的问题，再核对单位、时间范围和分母。数量重复用符号时注明每个符号的单位及余数处理。案例分析应记录读者如何在图表、符号和注释之间移动，以及装饰是否遮蔽了数据刻度。
