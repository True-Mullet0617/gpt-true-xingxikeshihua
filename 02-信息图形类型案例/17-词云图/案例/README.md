# 词云信息图｜案例

此目录用于归档**多件独立词云信息图**。每件作品必须有原始图片和一份配属的独立分析文档，并在同一个 CASE 文件夹中保存。

```text
案例/
├── README.md
├── CASE-0001-作品名称/
│   ├── 原图.png
│   └── 分析.md
└── CASE-0002-作品名称/
    ├── 原图.jpg
    └── 分析.md
```

> 以上仅表示未来的目录格式，不代表已有 CASE-0001 或 CASE-0002。当前正式案例数：**0**。

每件 `分析.md` 均按 A 数据逻辑、B 统计与计算、C 视觉编码、D 数据／信息架构、E 视觉叙事分析，并标注五大基础类型之一的唯一主归属及来源证据。
