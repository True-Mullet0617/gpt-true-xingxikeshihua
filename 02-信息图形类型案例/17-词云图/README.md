# 词云图

词云图以词汇作为全部画面元素。用词语的大小、字重、方向、颜色和疏密建立阅读层级，轮廓与空间感也由文字本身构成。

[返回类型索引](../README.md)

## 词汇与编排

- 从主题中提取关键词并归组，用较大的词建立视觉焦点，再用相关词补充语义和填充轮廓。
- 用字距、留白、对齐和方向变化组织阅读节奏。词汇可以叠排或沿曲线布局，关键字形仍应清晰可辨。
- 字号可映射词频、权重或编辑确定的优先级。使用数据映射时，在说明中注明字号的含义。

## 文字扭曲与 3D 表现

- 弯曲文字基线，或将文字沿球面、柱面、波面排布，通过透视缩放和方向变化形成空间感。
- 用字形挤出形成厚度，结合文字正面与侧面的明暗变化表现深度。
- 在缩小预览时检查主词的辨识度，控制字形形变、间距收缩和遮挡。
